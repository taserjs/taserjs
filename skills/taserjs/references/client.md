# Typed Client RPC (`@taserjs/client`)

Read when connecting frontend apps or test suites with the zero-codegen type-safe RPC client `@taserjs/client`.

## Client Overview

`@taserjs/client` provides an end-to-end typed proxy client based on the route manifest (`AppManifest`) generated by `@taserjs/cli`. It requires no code generation step beyond the manifest.

```bash
pnpm add @taserjs/client
```

## Client Initialization

Initialize the client with `createClient`:

```ts
// src/lib/api.ts
import { createClient } from "@taserjs/client";
import type { AppManifest } from "@/server/.taserjs/routes.gen";

export const api = createClient<AppManifest>({
  baseUrl: "/api",
  headers: () => {
    const token = typeof window !== "undefined" ? localStorage.getItem("token") : null;
    return token ? { Authorization: `Bearer ${token}` } : {};
  },
});
```

### Options (`CreateClientOptions`)

- `baseUrl`: Prefix URL for all calls (e.g. `"/api"` or `"http://localhost:3000/api"`).
- `headers`: Static record or dynamic sync/async function returning headers.
- `fetch`: Custom fetch implementation (useful for in-process testing with `app.request`).
- `onRequest`: Interceptor callback called before dispatching requests.
- `onResponse`: Interceptor callback called after receiving responses.

## Calling Route Methods

Endpoints are called as nested proxy properties matching route path segments, terminated by the HTTP verb prefixed with `$`:

### 1. Root & Static Routes

```ts
// GET /
const res = await api.$get();
const data = await res.json();

// GET /users
const res = await api.users.$get({
  query: { limit: 10, offset: 0 },
});
```

### 2. Dynamic Parameters (`:param` -> `_param`)

Dynamic path parameters are accessed with an underscore prefix and passed via `param`:

```ts
// GET /users/:id
const res = await api.users._id.$get({
  param: { id: "user_123" },
});

// PUT /lab/items/:id
const res = await api.lab.items._id.$put({
  param: { id: "5" },
  query: { notify: "true" },
  body: { name: "Updated Item" },
});
```

### 3. Catch-All Splats (`*` -> `_splat`)

```ts
// GET /files/*
const res = await api.files._splat.$get({
  param: { _splat: "documents/reports/2026.pdf" },
});
```

### 4. Multipart Form Uploads (`formBody`)

Use `formBody` from `@taserjs/client` to construct a typed `FormData` instance for endpoints with body mode `"form"`:

```ts
import { formBody } from "@taserjs/client";

const payload = formBody({
  title: "Avatar Upload",
  file: fileInput.files[0],
});

const res = await api.users.avatar.$post({
  body: payload,
});
```

## In-Process Testing Without HTTP

Test client calls in test suites (Vitest, Jest) without running an HTTP server by passing `app.request` to `fetch`:

```ts
import { describe, expect, it } from "vitest";
import { createClient } from "@taserjs/client";
import { app, type AppManifest } from "./.taserjs/routes.gen.js";

const client = createClient<AppManifest>({
  fetch: (url, init) => app.request(url, init),
});

describe("API Client", () => {
  it("fetches user by ID in-process", async () => {
    const res = await client.users._id.$get({ param: { id: "42" } });
    expect(res.status).toBe(200);

    const user = await res.json();
    expect(user.id).toBe("42");
  });
});
```

## Interceptors

Add request and response interceptors:

```ts
export const api = createClient<AppManifest>({
  baseUrl: "/api",
  async onRequest(request) {
    console.log(`[API Request] ${request.method} ${request.url}`);
    return request;
  },
  async onResponse(response, request) {
    if (response.status === 401) {
      // Handle token expiration or redirect to login
    }
    return response;
  },
});
```

## Verify

1. Run `npx tsc --noEmit` to verify that `api.users._id.$get(...)` matches route parameter types.
2. Verify that `res.json()` returns the type inferred from `.returns(...)`.
