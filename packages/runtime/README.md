# @taserjs/runtime

High-performance type-safe runtime engine for Taser.js backed by Hono.

## Installation

```bash
npm install @taserjs/runtime
# or
pnpm add @taserjs/runtime
```

## Documentation

Guides and API reference: [taserjs.dev](https://taserjs.dev)
