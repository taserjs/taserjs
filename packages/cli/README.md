# @taserjs/cli

Unified CLI for Taser.js: file scanning, manifest code generation, and project tooling.

## Installation

```bash
npm install -D @taserjs/cli
# or
pnpm add -D @taserjs/cli
```

The `taser` binary is available after install.

## Documentation

Guides and API reference: [taserjs.dev](https://taserjs.dev)
