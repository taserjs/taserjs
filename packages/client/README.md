# @taserjs/client

Type-safe client-side RPC and fetch proxy for Taser.js.

## Installation

```bash
npm install @taserjs/client
# or
pnpm add @taserjs/client
```

## Documentation

Guides and API reference: [taserjs.dev](https://taserjs.dev)
