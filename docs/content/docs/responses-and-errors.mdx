Taser handlers return `reply.*` results. This makes responses consistent and keeps return types tied to status codes.

## Returning JSON and text

```ts
import { reply } from "@taserjs/router";
import { t } from "../taser";

export const Route = t.get("/health").handler(() => {
  return reply.json({ ok: true });
});
```

For text responses:

```ts
import { reply } from "@taserjs/router";
import { t } from "../taser";

export const Route = t.get("/robots.txt").handler(() => {
  return reply.text("User-agent: *\nDisallow: /", { status: 200 });
});
```

## Common error replies

Taser includes helpers for common HTTP errors:

```ts
import { reply } from "@taserjs/router";
import { t } from "../taser";

export const Route = t.get("/private").handler(() => {
  return reply.unauthorized({ message: "Sign in required" });
});
```

Available helpers include `badRequest`, `unauthorized`, `forbidden`, `notFound`, `unprocessableEntity`, and `internalServerError`.

## Declaring return shapes with `returns`

Use `returns` to declare the shapes your route can return. This gives callers a precise type and lets you validate responses.

```ts
import { reply } from "@taserjs/router";
import { z } from "zod";
import { t } from "../taser";

const Todo = z.object({ id: z.string(), title: z.string() });

export const Route = t
  .get("/todo/:id")
  .returns({ 200: Todo, 404: z.object({ message: z.string() }) })
  .handler((ctx) => {
    const found = Math.random() > 0.5;
    if (!found) return reply.notFound({ message: "Todo not found" });
    return reply.json({ id: ctx.params.id, title: "Write docs" });
  });
```

## Handling not found

You can define a global not found handler in your app setup:

```ts
import { createTaserApp, reply } from "@taserjs/router";
import { context } from "./context";

export const t = createTaserApp()
  .context(context)
  .notFound(() => reply.notFound({ message: "Not Found" }));
```

## Handling unexpected errors

Use `onError` to catch unexpected errors once:

```ts
import { createTaserApp, reply } from "@taserjs/router";
import { context } from "./context";

export const t = createTaserApp()
  .context(context)
  .onError((error) => {
    console.error(error);
    return reply.internalServerError({ message: "Internal Server Error" });
  });
```
