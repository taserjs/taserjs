The `@taserjs/adapter-express` package allows you to mount a Taser application directly onto an Express instance.

---

## Installation

```bash
npm install @taserjs/adapter-express express
```

---

## Mounting on Express

```ts title="src/index.ts"
import express from "express";
import { createExpressHandler } from "@taserjs/adapter-express";
import { routeManifest } from "#src/routeManifest.gen.js";
import { t } from "#src/taser.js";

// 1. Initialize Taser application
export const app = t.create(routeManifest);
export type TaserAppRouter = typeof app;

// 2. Create Express server
const server = express();

// 3. Mount Taser under /api prefix (or root with /{*splat})
const taser = createExpressHandler(app);
taser.mount("/api{/*splat}", server);

// 4. Start listening
const port = Number(process.env.PORT ?? 3000);
server.listen(port, () => {
  console.log(`Express server running on http://localhost:${port}`);
});
```

---

## Mounting at Root vs Subpath

- **Subpath Mounting**: `taser.mount("/api{/*splat}", server)` routes all `/api/*` traffic to Taser.
- **Root Mounting**: `taser.mount("/{*splat}", server)` routes all root traffic to Taser.

---

## Using Express Middleware

You can use existing Express middlewares before mounting Taser:

```ts title="src/index.ts"
import express from "express";
import morgan from "morgan";
import cookieParser from "cookie-parser";
import { createExpressHandler } from "@taserjs/adapter-express";
import { app } from "./app";

const server = express();

// Global Express middlewares:
server.use(morgan("dev"));
server.use(cookieParser());

// Mount Taser:
const taser = createExpressHandler(app);
taser.mount("/api{/*splat}", server);

server.listen(3000);
```
