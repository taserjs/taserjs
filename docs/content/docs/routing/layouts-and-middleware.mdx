Layout files in Taser allow you to organize cross-cutting concerns (authentication, CORS, rate limiting, logging) and inject typed state into child routes without repeating code in every handler.

---

## What is a Layout File?

A layout file is any TypeScript file inside `src/routes/` that does not end with an HTTP method. It exports a `Middleware` constant initialized with `t.middleware(layoutId)`.

```ts title="src/routes/admin.ts"
import { reply } from "@taserjs/router";
import { t } from "#src/taser.js";

export const Middleware = t.middleware("admin").use({
  handler: async (ctx, next) => {
    const authHeader = ctx.headers.get("authorization");
    if (!authHeader?.startsWith("Bearer ")) {
      return reply.unauthorized({ message: "Admin authorization required" });
    }

    const token = authHeader.slice(7);
    const adminUser = await verifyAdminToken(token);
    if (!adminUser) {
      return reply.forbidden({ message: "Insufficient permissions" });
    }

    // Injects adminUser directly into ctx.state for all downstream routes
    return next({ adminUser });
  },
});
```

All route files in `src/routes/admin/` (or `src/routes/admin.*.ts`) automatically inherit this middleware and receive `ctx.state.adminUser` fully typed.

## Root Layout (`src/routes/$.ts`)

The root layout applies to every route in your application. It is the ideal place for global concerns like CORS, security headers, request timing, and tenant resolution:

```ts title="src/routes/$.ts"
import { cors } from "@taserjs/router/cors";
import { secureHeaders } from "@taserjs/router/secure-headers";
import { timing } from "@taserjs/router/timing";
import { t } from "#src/taser.js";

export const Middleware = t
  .middleware("/$")
  .use(
    cors({
      origin: ["https://app.example.com", "https://admin.example.com"],
      credentials: true,
    }),
  )
  .use(secureHeaders())
  .use(timing());
```

## Nested Layout Hierarchy & Execution Order

Taser executes layouts in a predictable cascading sequence from outermost to innermost:

```
src/routes/
├── $.ts                          -> [1] Root Layout (Global)
├── api.ts                        -> [2] Scoped /api Layout
└── api/
    ├── _auth.ts                  -> [3] Pathless Auth Layout
    └── _auth/
        ├── admin.ts              -> [4] Admin Role Layout
        └── admin/
            └── users.get.ts      -> [5] Route Handler (GET /api/users)
```

Execution sequence for `GET /api/users`:

```
[1. Root Layout: $.ts]
          │
          ▼
[2. API Layout: api.ts]
          │
          ▼
[3. Pathless Layout: _auth.ts]
          │
          ▼
[4. Role Layout: admin.ts]
          │
          ▼
[5. Route Handler: users.get.ts]
```

## Injecting Typed State

When middleware calls `next({ session })`, the properties merge directly into `ctx.state`. Downstream handlers access these properties with complete TypeScript inference:

<Tabs items={["Middleware", "Route Handler"]}>
  <Tab value="Middleware">
    ```ts title="src/routes/dashboard.ts"
    import { reply } from "@taserjs/router";
    import { t } from "#src/taser.js";

    export const Middleware = t.middleware("dashboard").use({
      handler: async (ctx, next) => {
        const session = await getSession(ctx.headers.get("cookie"));
        if (!session) {
          return reply.unauthorized({ message: "Invalid session" });
        }

        return next({ session });
      },
    });
    ```

  </Tab>
  <Tab value="Route Handler">
    ```ts title="src/routes/dashboard/metrics.get.ts"
    import { reply } from "@taserjs/router";
    import { t } from "#src/taser.js";

    export const Route = t.get("/dashboard/metrics").handler(async (ctx) => {
      // ctx.state.session is 100% typed from dashboard.ts:
      const { userId, workspaceId } = ctx.state.session;

      const metrics = await ctx.db.getWorkspaceMetrics(workspaceId);
      return reply.json({ userId, metrics });
    });
    ```

  </Tab>
</Tabs>

## Standalone Middlewares with `defineMiddleware`

To create reusable middlewares across different layout files or projects, use `defineMiddleware()`:

```ts title="src/middleware/rate-limit.ts"
import { defineMiddleware, reply } from "@taserjs/router";

export function rateLimiter(options: { maxRequests: number; windowSeconds: number }) {
  return defineMiddleware({
    handler: async (ctx, next) => {
      const clientIp = ctx.headers.get("x-forwarded-for") ?? "127.0.0.1";
      const remaining = await checkRateLimit(clientIp, options);

      if (remaining <= 0) {
        return reply.badRequest({ message: "Rate limit exceeded" });
      }

      return next({ rateLimitRemaining: remaining });
    },
  });
}
```

Attach it to any layout or route:

```ts title="src/routes/api.ts"
import { t } from "#src/taser.js";
import { rateLimiter } from "../middleware/rate-limit";

export const Middleware = t
  .middleware("api")
  .use(rateLimiter({ maxRequests: 100, windowSeconds: 60 }));
```
