If you have an existing project or prefer setting up dependencies manually without the `create-taserjs` wizard, this guide provides complete step-by-step instructions.

You can configure Taser in four ways:

1. **Vite Native Backend**: Standalone, lightweight server powered directly by Vite and `@taserjs/router-plugin/vite`.
2. **Vite + Nitro**: Multi-cloud deployments targeting Cloudflare Workers, Vercel, AWS Lambda, and Node servers via Nitro presets.
3. **Next.js App Router**: Embedded type-safe API router mounted inside Next.js.
4. **Host Framework Pass-Through**: Layering Taser file routes on top of an existing Express, Fastify, or Hono server.

## Setup 1: Vite Native Backend (Standalone)

Standalone mode leverages Vite for local development with instant Hot Module Replacement (HMR) and compiles an optimized production server bundle to `dist/`.

<Steps>
  <Step>
    ### 1. Install Dependencies

    Install `@taserjs/router`, `@taserjs/router-plugin`, `vite`, `srvx`, and your schema validator:

    <Tabs items={["pnpm", "npm", "bun", "yarn"]}>
      <Tab value="pnpm">
        ```bash
        pnpm add @taserjs/router zod
        pnpm add -D @taserjs/router-plugin vite srvx
        ```
      </Tab>
      <Tab value="npm">
        ```bash
        npm install @taserjs/router zod
        npm install -D @taserjs/router-plugin vite srvx
        ```
      </Tab>
      <Tab value="bun">
        ```bash
        bun add @taserjs/router zod
        bun add -d @taserjs/router-plugin vite srvx
        ```
      </Tab>
      <Tab value="yarn">
        ```bash
        yarn add @taserjs/router zod
        yarn add -D @taserjs/router-plugin vite srvx
        ```
      </Tab>
    </Tabs>

  </Step>

  <Step>
    ### 2. Configure `package.json`

    Configure the `#taserjs/router` subpath import and Vite lifecycle scripts:

    ```json title="package.json"
    {
      "name": "my-taser-app",
      "type": "module",
      "imports": {
        "#taserjs/router": "./src/taser.ts"
      },
      "scripts": {
        "dev": "vite",
        "build": "vite build",
        "start": "node dist/serve.mjs",
        "typecheck": "tsc --noEmit -p tsconfig.json"
      }
    }
    ```

  </Step>

  <Step>
    ### 3. Configure TypeScript (`tsconfig.json`)

    Include the `.taser/types/**/*.d.ts` directory to enable ambient route typing:

    ```json title="tsconfig.json"
    {
      "compilerOptions": {
        "target": "ES2022",
        "module": "NodeNext",
        "moduleResolution": "NodeNext",
        "paths": {
          "#taserjs/router": ["./src/taser.ts"]
        },
        "strict": true,
        "skipLibCheck": true,
        "isolatedModules": true,
        "noEmit": true
      },
      "include": ["src", ".taser/types/**/*.d.ts"]
    }
    ```

  </Step>

  <Step>
    ### 4. Create `vite.config.ts`

    Attach the `taser()` plugin to your Vite config:

    ```ts title="vite.config.ts"
    import { defineConfig } from "vite";
    import { taser } from "@taserjs/router-plugin/vite";

    export default defineConfig({
      plugins: [taser()],
    });
    ```

  </Step>

  <Step>
    ### 5. Create Router Instance and Context

    Create `src/context.ts`:

    ```ts title="src/context.ts"
    import { createContext } from "@taserjs/router";

    export const context = createContext({
      boot: () => ({
        logger: console,
      }),
      request: () => ({
        requestId: crypto.randomUUID(),
      }),
    });
    ```

    Create `src/taser.ts`:

    ```ts title="src/taser.ts"
    import { createTaserApp } from "@taserjs/router";
    import { context } from "./context.js";

    export const t = createTaserApp({
      response: { validate: true },
    }).context(context);
    ```

  </Step>

  <Step>
    ### 6. Create Your First Route

    Create `src/routes/index.get.ts`:

    ```ts title="src/routes/index.get.ts"
    import { json } from "@taserjs/router/reply";
    import { t } from "#taserjs/router";

    const GET = t.get("/");

    export type RouteContext = typeof GET.$Infer.Context;
    export const Route = GET.handler((ctx) => {
      return json({ message: "Welcome to Taser!", requestId: ctx.requestId });
    });
    ```

    Start the development server:

    ```bash
    pnpm dev
    ```

    To build and run in production:

    ```bash
    pnpm build
    pnpm start
    ```

  </Step>
</Steps>

## Setup 2: Vite + Nitro (Multi-Cloud / Serverless Presets)

When you need to deploy your Taser API to Cloudflare Workers, Vercel, AWS Lambda, Netlify, or clustered Node environments, pair Vite with Nitro:

<Steps>
  <Step>
    ### 1. Install Dependencies

    Install `nitro` alongside the Taser packages:

    <Tabs items={["pnpm", "npm", "bun", "yarn"]}>
      <Tab value="pnpm">
        ```bash
        pnpm add @taserjs/router zod
        pnpm add -D @taserjs/router-plugin nitro vite
        ```
      </Tab>
      <Tab value="npm">
        ```bash
        npm install @taserjs/router zod
        npm install -D @taserjs/router-plugin nitro vite
        ```
      </Tab>
      <Tab value="bun">
        ```bash
        bun add @taserjs/router zod
        bun add -d @taserjs/router-plugin nitro vite
        ```
      </Tab>
      <Tab value="yarn">
        ```bash
        yarn add @taserjs/router zod
        yarn add -D @taserjs/router-plugin nitro vite
        ```
      </Tab>
    </Tabs>

  </Step>

  <Step>
    ### 2. Configure `vite.config.ts` and `nitro.config.ts`

    Add both `taser()` and `nitro()` plugins to `vite.config.ts`:

    ```ts title="vite.config.ts"
    import { defineConfig } from "vite";
    import { nitro } from "nitro/vite";
    import { taser } from "@taserjs/router-plugin/vite";

    export default defineConfig({
      plugins: [taser(), nitro()],
    });
    ```

    Create `nitro.config.ts` to select your deployment target preset:

    ```ts title="nitro.config.ts"
    import { defineConfig } from "nitro/config";

    export default defineConfig({
      preset: "node-server", // or "cloudflare-module", "vercel", "aws-lambda", "bun", etc.
    });
    ```

  </Step>

  <Step>
    ### 3. Build & Run

    ```bash
    pnpm dev                  # Runs development server with HMR
    pnpm build                # Compiles output to .output/
    node .output/server/index.mjs # Starts production server (node-server preset)
    ```

  </Step>
</Steps>

## Setup 3: Next.js App Router Integration

To embed Taser within an existing Next.js 15+ application:

<Steps>
  <Step>
    ### 1. Install Dependencies

    ```bash
    pnpm add @taserjs/router zod
    pnpm add -D @taserjs/router-plugin
    ```

  </Step>

  <Step>
    ### 2. Configure `package.json` & `tsconfig.json`

    ```json title="package.json"
    {
      "imports": {
        "#taserjs/router": "./src/taser.ts"
      }
    }
    ```

    ```json title="tsconfig.json"
    {
      "compilerOptions": {
        "paths": {
          "@/*": ["./src/*"],
          "#taserjs/router": ["./src/taser.ts"]
        }
      },
      "include": ["next-env.d.ts", "**/*.ts", "**/*.tsx", ".taser/types/**/*.d.ts"]
    }
    ```

  </Step>

  <Step>
    ### 3. Configure `next.config.ts`

    Wrap your Next.js configuration with `createTaser`:

    ```ts title="next.config.ts"
    import createTaser from "@taserjs/router-plugin/next";
    import type { NextConfig } from "next";

    const withTaser = createTaser({
      basePath: "/api", // Route requests under /api to Taser
    });

    const nextConfig: NextConfig = {
      // standard Next.js options
    };

    export default withTaser(nextConfig);
    ```

  </Step>

  <Step>
    ### 4. Create Catch-All Route Handler

    Create `app/api/[[...slug]]/route.ts` (or `src/app/api/[[...slug]]/route.ts`):

    ```ts title="app/api/[[...slug]]/route.ts"
    import { taserApp } from "../../.taser/app";

    const handle = (request: Request) => taserApp.fetch(request);

    export const GET = handle;
    export const POST = handle;
    export const PUT = handle;
    export const DELETE = handle;
    export const PATCH = handle;
    export const OPTIONS = handle;
    export const HEAD = handle;
    ```

  </Step>

  <Step>
    ### 5. Add Routes

    Create `src/routes/users.get.ts`:

    ```ts title="src/routes/users.get.ts"
    import { json } from "@taserjs/router/reply";
    import { t } from "#taserjs/router";

    const GET = t.get("/users");

    export const Route = GET.handler(() => {
      return json({ users: [{ id: "1", name: "Alex" }] });
    });
    ```

    Next.js will now dispatch `/api/users` through Taser with complete compile-time type safety!

  </Step>
</Steps>

## Setup 4: Host Framework Pass-Through (Hono, Express, Fastify)

If you have existing Express, Fastify, or Hono routes, you can layer Taser file routing cleanly on top of your host server without rewriting legacy handlers.

<Tabs items={["Hono", "Express", "Fastify"]}>
  <Tab value="Hono">
    Create `src/server.ts` exporting your Hono application:

    ```ts title="src/server.ts"
    import { Hono } from "hono";

    const app = new Hono();

    // Legacy Hono routes:
    app.get("/legacy", (c) => c.text("Hello from Hono legacy endpoint!"));

    export default app;
    ```

    Taser dispatches matched file routes in `src/routes/` first. Any unmatched request seamlessly falls through to `app`.

  </Tab>

  <Tab value="Express">
    Install `express` and `srvx`, then create `src/server.node.ts`:

    ```ts title="src/server.node.ts"
    import express from "express";

    const app = express();

    // Legacy Express routes:
    app.get("/legacy", (_req, res) => {
      res.json({ message: "Hello from Express legacy endpoint!" });
    });

    export default app;
    ```

  </Tab>

  <Tab value="Fastify">
    Install `fastify` and `srvx`, then create `src/server.node.ts`:

    ```ts title="src/server.node.ts"
    import Fastify from "fastify";

    const app = Fastify();

    // Legacy Fastify routes:
    app.get("/legacy", async () => {
      return { message: "Hello from Fastify legacy endpoint!" };
    });

    await app.ready();

    export default app.routing;
    ```

  </Tab>
</Tabs>
