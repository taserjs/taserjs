Taser integrates natively with [Hono](https://hono.dev). You can pair Taser's file-based routing and cascading type safety with existing Hono routes and middleware using the **Host Pass-Through Architecture**.

---

## How It Works

When a request arrives:

1. **Taser Route Check**: If the URL matches a file route in `src/routes/`, Taser dispatches the request with full type safety.
2. **Host App Pass-Through**: If no Taser route matches, the request falls through to your exported Hono instance.
3. **404 Not Found**: If neither Taser nor Hono handles the request, Taser returns a standard 404 response.

```
[Incoming Request]
       │
       ▼
[Taser File Routes] ── Match? ──► [Execute Taser Route Handler]
       │ (No match)
       ▼
[Hono Host App] ──── Match? ──► [Execute Hono Route Handler]
       │ (No match)
       ▼
[404 Not Found]
```

## Quickstart

<Steps>
  <Step>
    ### 1. Scaffold with Hono Host

    ```bash
    pnpm create taserjs@latest my-hono-app --framework hono -y
    ```

  </Step>

  <Step>
    ### 2. Configure `src/server.ts`

    Create `src/server.ts` exporting your Hono application:

    ```ts title="src/server.ts"
    import { Hono } from "hono";

    const app = new Hono();

    // Existing or host-specific Hono endpoints:
    app.get("/host-info", (c) => {
      return c.json({ framework: "Hono", status: "online" });
    });

    export default app;
    ```

  </Step>

  <Step>
    ### 3. Add Taser Routes

    Create `src/routes/users.get.ts`:

    ```ts title="src/routes/users.get.ts"
    import { json } from "@taserjs/router/reply";
    import { t } from "#taserjs/router";

    const GET = t.get("/users");

    export const Route = GET.handler(() => {
      return json({ users: ["Alice", "Bob"] });
    });
    ```

  </Step>

  <Step>
    ### 4. Start Development

    ```bash
    pnpm dev
    ```

    - `http://localhost:3000/users` is dispatched through Taser.
    - `http://localhost:3000/host-info` is handled by your Hono application.

  </Step>
</Steps>

## Reusing Hono Middleware in Taser

`defineMiddleware()` accepts native Hono middleware functions directly:

```ts title="src/routes/$.ts"
import { defineMiddleware } from "@taserjs/router";
import { secureHeaders } from "hono/secure-headers";
import { t } from "#taserjs/router";

// Wrap any Hono middleware seamlessly
const honoSecurity = defineMiddleware(secureHeaders());

export const Middleware = t.middleware("/$").use(honoSecurity);
```
