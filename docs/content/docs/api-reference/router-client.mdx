The `@taserjs/router-client` package provides an end-to-end typed client proxy SDK.

---

## Core Functions

### `createClient<TApp>(options)`

Creates an auto-completing typed proxy client. Pass your server's `App` type or `RouteManifest` as `TApp` to infer all available endpoints, parameters, query schemas, and return contracts:

```ts
function createClient<TApp = never>(options: CreateClientOptions): Client<TApp>;
```

#### Options (`CreateClientOptions`)

<TypeTable
  type={{
    baseUrl: {
      description: "Base URL prefix for all requests (for example, 'https://api.example.com/api').",
      type: "string",
      required: true,
    },
    headers: {
      description:
        "Static header dictionary or async resolver function for dynamic Authorization headers.",
      type: "Record<string, string> | (() => Promise<Record<string, string>>)",
    },
    fetch: {
      description: "Custom fetch function (defaults to globalThis.fetch).",
      type: "typeof fetch",
      default: "globalThis.fetch",
    },
  }}
/>

### `formBody(fields)`

Encodes fields and file attachments into a `FormData` multipart payload:

```ts
function formBody(fields: Record<string, FormBodyField>): FormBody;
```

#### Field Types

<TypeTable
  type={{
    "fields[key]": {
      description: "Primitives (string, number, boolean) or binary attachments (Blob, File).",
      type: "string | number | boolean | Blob | File | null | undefined",
    },
  }}
/>
