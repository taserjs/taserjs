The `@taserjs/router-cli` package provides command-line tooling to generate ambient TypeScript definitions and scaffold empty route files outside the development server.

---

## Commands

### `taser generate`

Scans the routes directory, resolves project configuration, fills blank route files with starter boilerplate and file-synced path strings, and writes `.taser/types/routes.d.ts`.

```bash
# In package.json scripts (when installed as a dev dependency)
taser generate [--config <path>]

# On-demand execution via npx
npx @taserjs/router-cli generate [--config <path>]
```

<Callout type="info" title="Binary Name vs. Package Name">
  The npm package is `@taserjs/router-cli`, which provides the executable binary named `taser`. When
  added to `devDependencies`, npm/pnpm/yarn/bun link the `taser` binary into `node_modules/.bin`,
  allowing direct invocation in `package.json` scripts as `taser generate`. For ad-hoc runs without
  installing, use `npx @taserjs/router-cli generate`.
</Callout>

## Configuration Resolution

`taser generate` inspects your project build configuration:

1. **`--config <path>`**: Targets the specified configuration file directly (e.g. `vite.config.ts`, `nitro.config.ts`, `next.config.ts`).
2. **Current Directory**: When `--config` is omitted, searches the current working directory in priority order:
   - `vite.config.*`
   - `nitro.config.*`
   - `next.config.*`

If no valid Taser configuration is found, an error is reported. Configuration is required.

## Build vs. TypeScript Integration

Standard production builds with bundler integrations (`vite build`, `next build`) invoke the Taser plugin during compilation, automatically generating routes and emitting ambient types.

To run standalone TypeScript typechecking (`tsc --noEmit`) in CI pipelines or pre-commit hooks outside of a bundler build, prepend `taser generate` to your typecheck script so `.taser/types/routes.d.ts` is generated first:

```json title="package.json"
{
  "scripts": {
    "build": "vite build",
    "typecheck": "taser generate && tsc --noEmit -p tsconfig.json"
  }
}
```
