The `@taserjs/router-cli` provides code generation, route discovery, and developer tooling.

---

## Commands

### `taser generate` (alias: `taser gen`)

Scans the routes directory once and writes the generated manifest file.

```bash
taser generate [options]
```

### `taser watch` (alias: `taser dev`)

Watches route files and regenerates the manifest on save.

```bash
taser watch [options]
```

### `taser init`

Creates a starter `taser.config.json` in the current working directory.

```bash
taser init [--dir <path>]
```

### `taser scaffold <path>` (alias: `taser add`)

Generates a boilerplate route or layout file.

```bash
taser scaffold users/$id.get.ts
```

```json
{
  "$schema": "https://raw.githubusercontent.com/taserjs/taserjs/main/packages/router-cli/taser.config.schema.json",
  "routes": "src/routes",
  "output": "src/routeManifest.gen.ts",
  "entry": "src/taser.ts",
  "extension": true,
  "ignorePrefix": "_",
  "quotes": "single",
  "semi": false,
  "format": true,
  "validate": true
}
```
