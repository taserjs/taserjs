The `@taserjs/router` package is the core routing and context engine of the TaserJS ecosystem.

---

## Core Functions

### `createTaserApp(options?)`

Creates a new `TaserRouter` builder instance.

```ts
function createTaserApp(options?: CreateTaserAppOptions): TaserRouter;
```

### `createContext(definition)`

Defines application boot singletons and per-request metadata.

```ts
function createContext<TBoot, TReq>(definition: {
  boot?: () => Promise<TBoot> | TBoot;
  request?: (args: { native: unknown }) => Promise<TReq> | TReq;
}): ContextDefinition<TBoot, TReq>;
```

<TypeTable
  type={{
    boot: {
      description:
        "Executed once at server startup. Returns long-lived application singletons (database, Redis, loggers).",
      type: "() => Promise<TBoot> | TBoot",
    },
    request: {
      description:
        "Executed for every incoming HTTP request. Returns request-scoped state (requestId, startTime).",
      type: "(args: { native: unknown }) => Promise<TReq> | TReq",
    },
  }}
/>

---

### `defineHandler(options?)`

Constructs a standalone, reusable route handler.

```ts
function defineHandler(options?: {
  query?: Schema;
  params?: Schema;
  body?: Schema;
}): HandlerBuilder;
```

---

### `defineMiddleware(options)`

Constructs a standalone, reusable middleware unit.

```ts
function defineMiddleware<TState = unknown>(options: {
  query?: Schema;
  params?: Schema;
  body?: Schema;
  returns?: Record<number, Schema>;
  handler: (
    ctx: StandaloneMiddlewareContext,
    next: (state?: TState) => Promise<ReplyResult>,
  ) => unknown;
}): MiddlewareUnit;
```
