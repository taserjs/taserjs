Taser builds an app that speaks the Web standard `Request` and `Response` types. That app can then be mounted on the server you already run.

## Create the app

Every adapter starts the same way:

```ts
import { routeManifest } from './routeManifest.gen'
import { t } from './taser'

export const app = t.create(routeManifest)
export type TaserAppRouter = typeof app
```

## Express

Install:

```bash
npm install express
npm install @taserjs/adapter-express
```

Mount:

```ts
import express from 'express'
import { createExpressHandler } from '@taserjs/adapter-express'
import { app } from './app'

const server = express()
const taser = createExpressHandler(app)

taser.mount('/api{/*splat}', server)

server.listen(3000)
```

## Fastify

Install:

```bash
npm install fastify
npm install @taserjs/adapter-fastify
```

Mount:

```ts
import Fastify from 'fastify'
import { createFastifyHandler } from '@taserjs/adapter-fastify'
import { app } from './app'

const server = Fastify()
const taser = createFastifyHandler(app)

taser.mount('/api/*', server)

await server.listen({ port: 3000 })
```

## Node HTTP server

Install:

```bash
npm install @taserjs/adapter-node
```

Mount:

```ts
import { createServer } from 'node:http'
import { createNodeHandler } from '@taserjs/adapter-node'
import { app } from './app'

const server = createServer()
const taser = createNodeHandler(app)

taser.mount('/api', server)

server.listen(3000)
```

## Fetch runtimes (Hono style)

Because `app.fetch` already accepts a `Request`, you can run it in any runtime that calls a Fetch handler.

For example in Node using `@hono/node-server`:

```ts
import { serve } from '@hono/node-server'
import { app } from './app'

serve({ fetch: app.fetch, port: 3000 })
```
