**Taser** is a modern, type-safe, file-based router designed for scalable Node.js and edge HTTP services. It bridges the gap between clean filesystem architecture and strict type safety.

Traditional Node.js routing forces you to write manual route registries, perform unsafe type assertions on `req.user`, and maintain separate client types that drift over time. Taser solves these challenges by treating the filesystem as the source of truth, cascading middleware state through directory layouts, and generating a 100% typed client SDK.

```ts title="src/routes/users/$id.get.ts"
import { reply } from "@taserjs/router";
import { z } from "zod";
import { t } from "#src/taser.js";

const GET = t
  .get("/users/:id")
  .params(z.object({ id: z.string().uuid() }))
  .query(z.object({ includeProfile: z.coerce.boolean().default(false) }))
  .returns({
    200: z.object({ id: z.string(), name: z.string(), email: z.string() }),
    404: z.object({ message: z.string() }),
  });

export type RouteContext = typeof GET.$Infer.Context;
export const Route = GET.handler(async (ctx) => {
  // ctx.params.id is typed as string (UUID)
  // ctx.query.includeProfile is typed as boolean
  // ctx.state contains data injected by layout middlewares
  const user = await ctx.db.findUserById(ctx.params.id);
  if (!user) {
    return reply.notFound({ message: "User not found" });
  }

  return reply.json(user);
});
```

## How Taser Works

Taser operates around a simple, powerful lifecycle:

```
[HTTP Request]
       │
       ▼
[Server Adapter] ──── Express, Fastify, Hono, Node HTTP, Edge
       │
       ▼
[Dual Context] ────── Boot singletons + Request-scoped metadata
       │
       ▼
[Layout Middleware] ── Root ($.ts) and nested folder middleware chains
       │
       ▼
[Input Validation] ── Standard Schema parsing for params, query, body
       │
       ▼
[Route Handler] ───── Fully typed ctx execution
       │
       ▼
[Response Contract] ── .returns() compiler check & payload formatting
       │
       ▼
[Typed Response] ──── Status-discriminated JSON or stream reply
```

<Callout type="info" title="Zero Runtime Overhead">
  Taser compiles file structures into a static route manifest during development watch mode (`taser
  watch`). At runtime in production, routing runs on ultra-fast radix trees with minimal overhead.
</Callout>
