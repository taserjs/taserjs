**Taser** is a type-safe, file-based router for Node.js HTTP APIs. You define routes as files, compose layouts and middleware with full inference, mount on the framework you already use, and export a typed client that matches your handlers.

## Quick start

Scaffold a project in under a minute:

```npm
npm create taserjs@latest
```

Pick **Express**, **Hono**, **Fastify**, or plain **Node**, then run your package manager’s `dev` script. The CLI watches route files and regenerates the manifest as you edit.

## Why Taser?

- **File-based routes**: Drop a handler file. Codegen keeps the manifest in sync.
- **Types on the wire**: Query, params, body, returns, and context flow through middleware chains.
- **Typed client**: Export `TaserAppRouter` and call your API with the same types your handlers use.
- **Your runtime**: One router definition. Adapters for Express, Hono, Fastify, and Node.

## A taste

Define a route:

```ts
import { reply } from '@taserjs/router'
import { z } from 'zod'
import { t } from '../taser'

export const Route = t.get('/search', {
  query: z.object({ q: z.string().min(1) }),
})
  .returns({ 200: z.object({ q: z.string() }) })
  .handler((ctx) => {
    return reply.json({ q: ctx.query.q })
  })
```

Call it with the typed client:

```ts
const response = await client.search.$get({ query: { q: 'taser' } })
const json = await response.json()
// json is inferred from returns[200]
```
